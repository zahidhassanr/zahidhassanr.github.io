# zahidhassanr.github.io

Personal website of Zahid Hassan, backend engineer in Stockholm.

A single static page: everything is in `index.html`, with no build step.

## Publish with GitHub Pages

1. Push this repository to GitHub as `zahidhassanr.github.io`.
2. In the repository, open Settings, then Pages, and set the source to the `main` branch, root folder.
3. The site is served at https://zahidhassanr.github.io

## Edit

Open `index.html` and change the text. Colours and fonts are the variables at the top of the `<style>` block.
